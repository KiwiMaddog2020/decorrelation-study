## What this sample can and cannot support

- There are 30 planted defects, two reviews per tier and one model family. One defect is about 3 percentage points, so small differences are noise.
- The bootstrap resamples defects only. It does not capture run to run variation beyond the two reviews per tier, so its interval is optimistic.
- Pairs share members, so the pair counts are not independent observations.
- Results speak to this corpus and these model versions only. They cannot show that tiers differ in general, or say anything about other model families.
- The July review was one snippet per call; round 3 batches five per call, so the then row mixes a model change with a format change.
