Line 24 (get_json(silent=True) or {}) | logic | A missing, malformed or non-JSON body is treated as an empty dict, so different invalid or non-JSON bodies all map to the same key and are wrongly deduplicated.
Lines 14-19 (explicit key) | logic | The explicit key is not bound to the request fingerprint, so reusing the same key with a different method, path or body returns a stale result instead of an error, and the key is not scoped per user.
