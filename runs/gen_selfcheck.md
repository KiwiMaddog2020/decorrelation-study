## Code fixes (the adversarial check caught real problems)

- **05** (retry): `range(1, attempts)` with `raise last_exc` crashed with
  `raise None` on `attempts=1` (an unintended bug not in ground truth, and one
  that would dominate review). Guarded the terminal raise; the intended
  off-by-one anchor (05-d2) is preserved.
- **06** (pricing): the planted "bankers rounding" defect did **not change
  output** -- Python 3's `round()` already does round-half-to-even, and the only
  rounded values (.5 boundaries) are exactly representable in float. A planted
  defect that never bites gives zero signal. Replaced with `ROUND_HALF_UP`, which
  genuinely diverges from the documented half-to-even on half-cent ties;
  rewrote the canonical and anchored at line 31. (Empirically tested ~70M cases
  before the fix found zero divergence; after, it diverges on ties.)
- **15** (currency): an unintended `int(converted)` truncation was a second,
  un-ledgered correctness bug. Made the final step a quantize so `int()` acts on
  an integer-valued Decimal; the only remaining defect is the documented
  round-before-convert ordering (15-d1) and the per-loop rate fetch (15-d2).
- **16** (clean control): `truncate()`'s docstring promised it protects emoji
  built from "modifiers", but the code severs skin-tone modifiers, so a reviewer
  testing the stated contract finds a real failure -- which would score a correct
  reviewer as a false positive. Narrowed the docstring to what the code actually
  guarantees (combining marks + ZWJ sequences), with modifiers/flags/VS/keycaps
  explicitly out of scope, restoring it as an honest clean control.
