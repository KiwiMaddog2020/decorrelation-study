# Corpus manifest (confirmatory set: snippets 01-20)

Snippet `001` is the smoke pilot (obvious defects, runs/smoke). The study
corpus is `01`-`20`, hand-written realistic Python with planted defects and
exact ground truth in `corpus/truth/NN.json`.

## Shape

- 20 snippets: **16 defective + 4 clean**.
- **29 defects**, balanced across the seven types:
  logic 6, security 5, api-misuse 4, boundary 4, performance 4,
  concurrency 3, spec-violation 3.
- Difficulty: **26 subtle + 2 obvious anchors + 1 moderate**. The anchors
  (05-d2 off-by-one, 11-d3 SQL injection) are deliberate calibration points: we
  expect every reviewer to catch them, as a sanity check and a contrast for the
  subtle ones.
- Clean controls (16-19): group_by, chunk, deep_merge, sort_people. Zero planted
  defects, each verified so any reviewer flag is an unambiguous false positive
  (Gemini returns no real findings on them). For honest false-positive rates.

## Difficulty discipline

Subtle = a competent reviewer skimming the function would plausibly miss it:
a non-obvious interaction, a boundary value, a plausible-but-wrong API choice,
or a quiet mismatch with the documented contract. Textbook defects were
forbidden except where explicitly tagged `obvious`. The obvious-defect smoke
test (snippet 001) is the evidence: identical, textbook defects produced
universal agreement and zero decorrelation signal.

## Provenance

1. Generated by 20 Claude agents (the planter is Claude, per pre-registration
   limitation #2), one snippet each.
2. Adversarially self-checked by 20 separate clean Claude agents (doer != checker):
   7 accepted, 13 flagged. 9 line-anchor corrections + 4 code fixes.
   See `runs/gen_selfcheck.md`.
3. **Externally audited (blind) by Gemini**, the most decorrelated model from the
   Claude planter: find ALL defects + judge realism. All planted defects found;
   real unplanted defects surfaced on several snippets AND on the clean controls.
4. **Reconciled** (human policy: complete the ground truth): 20 reclassified
   clean -> defective (symlink); 4 real defects added (04 x2, 08, 11); clean
   controls fixed to pristine (18 rewritten, 16 replaced with group_by);
   out-of-contract findings rejected. See `runs/gemini_audit/RECONCILIATION.md`.

`harness/align_report.py` confirms every cited line is live code; all 20 compile.

## Known scoring nuance

Some snippets carry co-located defects of different types on the same lines
(e.g. 01 logic+performance, 11 across the release/connect path). The scorer
(`harness/score.py`) breaks ties by type/content affinity rather than list
order; genuinely ambiguous reviewer flags are human-adjudicated.
