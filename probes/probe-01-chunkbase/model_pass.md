# Probe 01 model pass (SEALED)

**Do not read until your human pass is logged.** Reading this first contaminates you as
a blind subject, which is the exact mistake the H3 reframe was about.

Clean-room prediction for a generic first-time Bedrock user. No human reaction was seen
in producing this. Per step: valence (delight / neutral / friction), a one-line
predicted reason, and a predicted stuck-probability.

1. **Find the right tool.** Friction (low). The landing page shows several apps; a
   first-timer pauses to work out that "Seed Map" is the one, but the names are clear
   enough. Stuck: unlikely.
2. **Open Seed Map.** Neutral. One click, a map loads. Smooth.
3. **Set platform and version.** Friction (medium). The user has to know to switch from
   Java to Bedrock; if they miss the toggle the map is wrong. Stuck: possible, they may
   not notice the toggle.
4. **Find and enter the seed.** Friction (high). The hardest step: the seed lives in
   game (world settings or a command), not in Chunkbase, so the user leaves, hunts for
   the seed, comes back. Stuck: likely. This is the predicted drop-off.
5. **Read the map, find villages.** Friction (medium). Many structure icons; the user
   has to filter or hunt for the village marker among them. Stuck: possible.
6. **Read coordinates.** Neutral. Hover or click gives X and Z; readable.
7. **Translate to in-game navigation.** Friction (medium). The user maps X/Z to in-game
   directions and travels; some confusion about which way is which. Stuck: possible.

**Model's single predicted worst step:** step 4 (finding the seed).
**Model's predicted overall:** usable, with a real hunt at the seed step.
